# iTech Solutions — Landing Page

Landing page de venta y reparación de iPhone en Santiago, Chile. React + Vite, sin frameworks de CSS (diseño propio "Santiago Street Tech": bordes duros, sombras offset, tipografía Anton + Space Grotesk + Space Mono).

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run preview
```

## Estructura

- `src/App.jsx` / `src/App.css` — página principal (Hero, catálogo, diagnóstico, plan canje, reseñas, contacto, ubicación).
- `src/components/Layout.jsx` — Header y Footer compartidos.
- `src/pages/` — rutas de Términos y Privacidad.
- `src/assets/` — imágenes usadas en el sitio.
